Original title: **Fair-play Dataset Schema v1**

Historically recorded as generated by `./one_combat.elf fairgen` with
`STS_SEARCHER3=1`. That invocation alone does not select
`ScumSearchAgent2::playoutBattleFair`; the intended current invocation also
needs `STS_FAIR=1`.

## File 1: Value CSV (`fair_val.csv`)

One row per combat decision. The same fight outcome labels every decision in that fight.

| Column | Type | Description |
|---|---|---|
| seed | uint64 | Game seed (metadata only — not used as feature) |
| fightIdx | int | 0-based fight index within the run |
| `<1766 features>` | float | Canonical combat state features (see CombatValueNet.cpp) |
| won | int (0/1) | Whether the player won this fight |
| endHp | int | Player HP at fight end |

**Feature blocks** (1766 total): base scalars (26), powers (24), relics (128), hand cards (371), draw pile (371), discard (371), exhaust (371), enemy aggregate (2), per-monster slots (45), potions (44), misc context (5), relic counters (8).

## File 2: Policy CSV (`fair_pol.csv`)

One row per root edge per MCTS decision. Multi-action decisions produce multiple rows.

| Column | Type | Description |
|---|---|---|
| seed | uint64 | Game seed (metadata only) |
| fightIdx | int | Fight index |
| decIdx | int | Decision index within the fight (reset per fight) |
| `<1766 state features>` | float | Same as value CSV |
| `<14 action features>` | float | aIsCard, aIsPotion, aIsEndTurn, aIsSelect, aCardId, aCardCost, aCardUpg, aCardAtk, aCardSkl, aCardPow, aTargetsEnemy, aTargetHp, aPlayOrder, aObtainWeight |
| visit | int64 | Number of MCTS simulations that selected this edge |
| total | int64 | Total simulations at this decision root |

The policy target π = visit^τ / Σ(visit^τ) for temperature τ. Store original visits, not normalized.

## Provenance

- Teacher: BattleScumSearcher3 (ISMCTS, 64 particles, 6 RNG streams)
- Sims per decision: 1000
- Agent seed: game seed (bc.seed)
- RNG: composite hash(agentSeed, visibleHash, decisionIdx)
- Ascension: 0
- Character: Ironclad

## Train/Test Split

Split by **game seed**, not by row. All rows from a seed stay together.

```
train: seeds 0..N_train-1
val:   seeds N_train..N_train+N_val-1
test:  seeds N_train+N_val..N_end
```

Recommended: 70/15/15 split.

## Hidden Fields Audit

No hidden RNG fields in features. The 1766 features contain only visible information:
- Player stats (HP, block, energy, strength, dexterity, focus, artifact, gold)
- Player powers (demon_form, metallicize, vulnerable, weak, frail, etc.)
- Relic presence (128 binary flags)
- Per-zone card-id counts (hand, draw, discard, exhaust — multiset only, order hidden)
- Enemy aggregate (incoming damage total, count of attacking monsters)
- Per-monster stats (id, HP, block, strength, intent damage, attacking flag, vuln, weak, poison)
- Potion counts per ID
- Turn number, ascension level, encounter type
- Relic/persistent counters (happyFlower, incenseBurner, etc.)
- Cards played this turn (attack/skill counters)

The `seed` column is metadata, not a feature.

## Recommended Training Sampler Strata

- act and floor
- encounter/monster type
- combat turn number
- HP fraction
- number of legal actions
- root policy entropy
- close vs obvious decisions
- win vs death outcome
- potion decisions
