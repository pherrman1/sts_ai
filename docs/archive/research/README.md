# Archived research material

Last verified: 2026-08-11.

These files preserve dated plans, handoffs, session snapshots, and resolved
investigation evidence. They are not current instructions.

- `plans/` contains completed, superseded, or parked experiment plans.
- `sessions/` contains agent-session reports and handoffs.
- `encounter-marg/` contains intermediate snapshots superseded by the final
  maintained report at
  `docs/knowledge-base/encounter-marg-final-summary-2026-08-10.md`.
- `s3-reuse/` contains intermediate and final investigation reports distilled
  into
  `docs/knowledge-base/decisions/s3-obs-stable-reuse-promotion.md`.

Use `docs/knowledge-base/evaluation/current-research.md` for current research
routing, `docs/knowledge-base/evaluation/current-baselines.md` for qualified
configurations, and `EXPERIMENTS.md` for chronological evidence.
