# Session retrospective lessons

Purpose: Persistent evidence about recurring agent-workflow problems and
attempted remedies. This is not canonical implementation truth.

## Active patterns

No patterns recorded. Add one only when it is repeated, costly, or clearly
high-impact. Merge duplicates; mark resolved patterns instead of deleting their
history; never store branch names, temporary SHAs, line numbers, raw secrets,
or long transcript excerpts; and link to canonical maintained knowledge rather
than duplicating it.

