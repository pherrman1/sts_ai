## Decisions / findings

1. **Q_win objective implemented and trained.** The Tier-B `labelWon` was
   already the soft win-probability target (0/1 terminal + `vStateWin`
   bootstrap, futures-averaged) — no datagen schema change was needed for the
   label itself. Trainer (`train_strategic.py`) now: BCE on `labelWon`,
   `q_hp` (`labelHp/maxHp`) and `q_floor` (`labelFloor/60`) aux heads,
   probability-scale metrics (q_brier, q_cal_max), `STRAT_PATIENCE` early
   stop.
2. **New artifact magic `OOC_STRAT_V5`; legacy V3 stays loadable.** The new
   binary accepts both magics; a legacy V3 full-stack run is **bit-identical
   seed-for-seed to `ref_m1.csv` (39.8%)**, so all historical references
   remain reproducible. V5 applies the sigmoid to Q/aux at inference.
3. **V_win bootstrap is mildly over-predicting, NOT grossly miscalibrated —
   an initial checker bug misled the finding.** My first calibration check
   treated `base_score` (a probability) as if it were added directly to leaf
   margins, while the C++ `WinNet::predict` converts it to logit space first
   (`log(p/(1-p))`) — a ~1.0 logit inflation that produced a false "Brier
   0.232 / max decile 0.42" headline. After the logit fix and a
   **C++/Python parity check** (new `winnettest` mode + `parity_vwin.py`:
   max |diff| 0.000000 over 200 rows), the true numbers are Brier 0.153, log
   loss 0.471, max decile 0.18 — typical few-wins XGBoost over-confidence at
   mid-high values. **Inference:** V_win error still propagates into every
   censored `labelWon` (76% of rows) and biases Q_win labels upward, but the
   bias is modest and monotone; the fix is a small Platt/isotonic
   recalibration (Wave A2, §95), which the isotonic map reduced to 0.08 max
   decile on held-out seeds.
4. **Fresh training data generated on the GCP server** (new seeds
   200000–201439, 1,440 seeds / 900,916 rows / 1.92 GB, ~20 min, 24 threads;
   §73 config minus the absent `v_combat_fair_trees.txt` VNet leaf — recorded
   deviation), pulled to this laptop for the retrain.
5. **V3 Q_win retrained on this laptop's CPU** (40-epoch budget,
   `STRAT_PATIENCE=6`): early stop at epoch 30, best epoch 24. Held-out
   policy top-1 0.792 / val_pol_ce 0.474; Q_win Brier 0.053 / cal 0.016;
   q_hp_mae 0.257, q_floor_mae 0.080. Artifacts in
   `selfplay/models/ooc_strategic_qwin.*`.
6. **Process:** the first training run's final `torch.save` was interrupted
   (16 KB truncated .pt, no metrics JSON); rerun reused the intact 1.8 GB
   `_state.bin` (no mmap rewrite) and completed cleanly with output to a log
   file. Smoke-before-train done as requested: synthetic 2-epoch trainer run,
   exporter parity both magics, loader dual-magic, legacy bit-identity, V5
   gate smoke at probability-point margins.
