## Decision

Implemented the §2 contract in `apps/one_combat.cpp`:

- `oocShopBeamPolicy(GameContext&)` (~:5223) — beam over deterministic shop purchases. Each node is a `detachedCounterfactualCopy` (map detached); expansion uses `GameAction::getAllActionsInState` (already affordability-filtered) for SHOP_ROOM plus the removal-target picks on the CARD_SELECT(REMOVE) successor of CARD_REMOVE. SKIP (leave) terminates a node as a leaf. Any other successor screen (e.g. a bottled-relic BOTTLE select) terminates the branch as a leaf — rare, not part of the purchase contract.
- Leaf value = per-screen value head on `ScreenState::SHOP_ROOM` (`shopBeamLeafValue` ~:5238): V3 `richFeatureVec` + `predictValue(state, SHOP_ROOM)`, or the token-net path `buildTokState` + `predictValue(ts.glob, SHOP_ROOM)` when `g_oocStrategicTokNet.ok`.
- Dedup: per-ply fingerprint `shopBeamNodeFingerprint` (~:5209) = FNV-1a over screen + select-screen type, gold, the `StratFingerprint` digests (deckSum/deckUpSum/deckHash, relicSum/relicHash, potions), and the full shop offer set (removeCost, 13 prices, 7 card ids+upgraded, 3 relic ids, 3 potion ids). Per-ply only: every shop-buy ply strictly spends gold, so equal-gold duplicates cannot occur across plies.
- Beam keeps the top `width` children per ply by leaf value; dropped children become buy-then-leave leaf candidates; every SHOP beam node's own state is a leave-leaf candidate.
- Executes the first action of the best-scoring sequence on the live gc. If the best leaf is the root itself (leave), executes SKIP (leave) and returns true: the beam owns the decision while enabled (mutual exclusion with the one-ply gate).
- Wiring: `runFullRunOOC` (~:2202) and `runTraceRun` (shop branch ~:2582, remove-select branch ~:2586) try the beam before `oocOnePlyShopPolicy` / `removeSelectVPolicy`. Env parse in `main()` after the BOSS_RELIC block (~:6639); `bestBench` banner now shows `shop-beam=ON/off`.
- Env flags: `STS_OOC_SHOP_BEAM` (default off), `STS_OOC_SHOP_BEAM_WIDTH` (default 32, clamped 4..256 at use), `STS_OOC_SHOP_BEAM_DEPTH` (default 0 = until leave/no affordable actions), `STS_OOC_SHOP_BEAM_BUDGET` (default 4096, clamped 64..65536 at use — hard global cap on expanded nodes per decision).

## Rationale

- **Termination**: each purchase ply strictly spends gold (prices ≥ 12; removal ≥ 50), so depth is bounded by gold even with the default unbounded depth; the budget guard additionally caps pathological shops (Courier restock cycles still spend gold).
- **Determinism/hidden info**: shop transitions are deterministic; THE_COURIER restocks are the only RNG consumers and the clones advance the same copied RNG stream the live run will, so the restocked offers a leaf head reads are exactly the offers the player will see after the buy. No future-encounter/event information enters the search — per contract §2 and the B3 audit's 1b finding (copy carries true streams; the flagged leaks were future encounters, not deterministic transitions).
- **Dropped-children-as-leaves**: gives the search a complete "buy prefix then leave" plan for every explored node, so pruning cannot silently discard the best terminal.
- **Leave-ownership**: when the beam is enabled it is the shop decision-maker (contract: beam first, else one-ply gate, else shopVPolicy); returning false would hand the decision back to the gate, contradicting the exclusion.

## Alternatives considered

- Treat CARD_REMOVE's successor as a leaf without expanding the REMOVE select — rejected: the removal target is a deterministic part of the purchase and the contract's node state is (offers, gold, deck); expanding it keeps the beam complete.
- Cross-ply dedup — rejected: gold strictly decreases each purchase ply, so a state cannot recur at a deeper ply; per-ply dedup is sufficient and cheaper.
- Return false when the beam's best leaf is "leave" (fall through to the gate) — rejected: violates beam-first mutual exclusion (see rationale).
- Hand-prune potion buys at full capacity — rejected: executor legality is the contract's filter; the value head naturally ranks the wasted-gold buy low.
