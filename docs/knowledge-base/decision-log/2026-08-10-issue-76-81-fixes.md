# 2026-08-10 — issues 76, 81 fixed (PVNet device line, v_server locked predict)

Date: 2026-08-10
Session/task: Investigator-audit fix pass on `train_combat_pvnet.py` and `v_server.py`

## Decision

- **Issue 76 (silent CPU fallback):** `train_combat_pvnet.py` now prints
  `device: {DEVICE}` (flush=True) immediately after device selection, matching
  the `device:` line convention of `train_strategic.py` and the
  "training on {DEVICE}" line of `train_value_combat.py`. A run that silently
  fell back to CPU is now visible in startup output.
- **Issue 81 (unlocked `WIN_BOOSTER.predict`):** in `v_server.py::decide_nn`
  the `WIN_BOOSTER.predict` call is now wrapped in `with LOCK:`, matching the
  existing `_win_predict` pattern. `decide_nn` is no longer the only unlocked
  model call in `v_server.py`; correctness no longer depends on installed
  xgboost predict thread-safety.

## Rationale

- #76: AGENTS.md instructs operators to check the startup `device:` line
  before assuming a run is progressing; a silent CPU fallback on a multi-
  million-row run wastes hours. The print is placed after the if/else so the
  final selected DEVICE (cuda or cpu) is reported.
- #81: every other model call in `v_server.py` (torch `_nn_predict`,
  `_meta_predict`, `_win_predict`, heal/gold/floor helpers, direct endpoints)
  already serializes on the module-global `LOCK`; the `decide_nn` GBM call was
  the only exception. `LOCK` is resolved at call time, so defining it below
  `decide_nn` in the module is fine.

## Alternatives considered

- A dedicated second lock for the GBM — rejected: there is a single shared
  predictor set and the established pattern is one global `LOCK`; a second
  lock adds contention-free complexity without benefit.

## Evidence

- `train_combat_pvnet.py:53-56`: `print(f"device: {DEVICE}", flush=True)`
  after the CUDA availability if/else.
- `v_server.py:194-200`: `with LOCK:` wraps the `WIN_BOOSTER.predict` call in
  `decide_nn`; `v_server.py:721-723` (`_win_predict`) shows the matched pattern.
- `python3 -m py_compile train_combat_pvnet.py v_server.py`: PASS.
