This is the fresh 32-seed follow-up authorized by the N16 smoke. It uses seeds
80--111, separate from the N16 smoke's seeds 64--79.

## Configuration

Both arms used Ironclad A0, fair RNG, exact-root budgets, allocated reuse cap
131072, native OOC, adaptive CTM budgeting off, no OOC MCTS, sequential arms,
and the same `one_combat` executable. The flat control disables adaptive
Silver. The treatment is the frozen retained-root policy:

```text
fresh root                         -> 10,000 simulations
retained root, 500-gap >= 0.2932885906040268 -> stop at 500 new simulations
retained root, otherwise           -> continue same search to 10,000
one-action/forced root             -> 10,000 simulations
```

## Results

| Measure | Flat 10k control | Retained-root treatment |
| --- | ---: | ---: |
| Wins | 22/32 | 24/32 |
| Mean final floor | 47.84 | 48.31 |
| Mean final HP | 32.53 | 30.97 |
| Wall time | 235.06 s | 135.55 s |
| Silver simulations added | 142,010,000 | 86,146,500 |
| Scaling decisions | 14,201 | 14,403 |
| Fresh roots | 807 | 813 |
| Retained roots | 13,394 | 13,590 |
| Exact reroots | 9,285 | 9,416 |
| Reroot fallbacks | 4,916 | 4,987 |

The treatment reduced added Silver simulations by **39.34%** and outer wall
time by **42.33%**. It stopped 6,093/14,403 decisions at 500 (42.30% of all
treatment decisions, 43.65% of non-forced decisions, and 44.83% of retained
roots). The 443 one-action/forced roots and all 813 fresh roots continued to
10,000. Every 500-stop row passed the retained/non-forced/threshold invariant
check.

There were four paired win disagreements: three treatment-only wins and one
control-only win. The treatment therefore has a descriptive +2/32 win
difference. Final-floor disagreements occurred on six pairs and final-HP
disagreements on 22 pairs. This is gameplay evidence at the requested N32
resolution, not proof of universal safety or action equivalence; the policy
changes retained-tree state by design.

Classification: **`PER_DECISION_SIGNAL_PROMISING`** — retained-root adaptive
search only. Fresh-root early stopping remains rejected. The result supports
the compute-saving retained-root treatment as a prospective qualification
candidate, but it does not authorize changing the default or treating the
policy as universally safe without a separately approved deployment gate.
