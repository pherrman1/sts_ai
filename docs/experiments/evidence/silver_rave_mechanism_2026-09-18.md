# Silver same-turn CARD RAVE mechanism screen (2026-09-18)

## Scope and provenance

This is a diagnostic-only mechanism screen. It does not change Silver's
default behavior, gameplay dispatch, rollout policy, chance handling, or any
production configuration. The implementation is opt-in through the existing
root replay runner's `--rave-screen` option.

The frozen 64 roots and Teacher-A/B labels were reused from the qualifying
single-source-seed root set in `silver_root_mechanism_2026-09-17.md`; labels
were not regenerated. Their declared executable provenance is
`06d9de36d1c2e07c7e0420a0752ae9a4d7fd738e`. The current-main descendant had
only later complete-fight replay API changes in the relevant paths before this
experiment. Replay rows were generated by the RAVE implementation head
`999c0ea4b577e7c98ae8716d67a6bcf4e81b2647` (working-tree head at execution);
the row-level declared teacher provenance remains the older SHA by contract.

## Frozen protocol

- 64 selected roots, all from source seed `0`; mechanism screen only.
- Teacher-A: preserved 10,000-simulation labels. Teacher-B: preserved
  independent 25,000-simulation judgment labels.
- Four common deterministic replicates, fresh search and no reuse, 32
  simulations per replay.
- A: ordinary native-order UCT; R8/R32/R128: same search with same-turn
  CARD-only RAVE and K 8/32/128.
- No policy prior, PUCT, model, training, gameplay gate, or whole-game seed
  run.

The RAVE key is `(card id, upgraded, specialData, costForTurn,
freeToPlayOnce, target monster index)`. Hand/source index and uniqueId are
excluded. END_TURN, potions, card-select actions, chance nodes, and actions
from later turns are excluded. A matching key updates an ancestor edge at
most once per simulation. Selection uses unchanged unvisited handling and
UCT exploration, with `Q_mix=(1-beta)Q_normal+beta Q_rave` and
`beta=sqrt(K/(3*N+K))`, where N is the decision-node simulation count.

## Results

| Arm | Mean B-regret | B-best | Wall seconds | Simulations/sec |
| --- | ---: | ---: | ---: | ---: |
| A | 2.739821 | 44.5313% | 0.304932 | 26,865 |
| R8 | 2.635180 | 42.1875% | 0.322128 | 25,431 |
| R32 | 2.663354 | 39.4531% | 0.321467 | 25,483 |
| R128 | 2.939709 | 35.9375% | 0.321314 | 25,495 |

Primary R32 minus A, with roots as the bootstrap unit and 10,000 resamples
(seed `20260917`): mean regret difference **-0.076467**; 95% CI
**[-0.420937, +0.188419]**. R32 improved/worsened/tied **11/17/36** roots.
The maximum adverse root delta was **+2.206586**, root `0/2/27/27/2`.
R32 B-best changed by **-5.0781 percentage points**.

RAVE coverage diagnostics for R32 were **20,668 updates**, **6,904 eligible
edges**, **1,789 eligible decision nodes**, and **1,789 covered nodes**:
100% node coverage and 2.994 samples per eligible edge. R8 had 20,738 / 6,829
and R128 20,707 / 6,936 updates / eligible edges respectively; both also had
100% node coverage. This is therefore an informative null screen rather than
a no-coverage failure.

## Decision

**RAVE_SCREEN_INCONCLUSIVE.** The primary regret CI crosses zero; the mean is
negative but B-best is non-positive, so the predeclared positive or negative
criteria are not met. The result is not a gameplay or run-level
generalization claim because all roots came from source seed `0`. A future
confirmation, if authorized, should use fresh source seeds (the handoff
suggested roughly 16 seeds × 2 roots) and the same frozen arm definitions.
