# Post-primary GEN2 interpretation — exploratory only

This specification is prepared without opening the 32-source tranche's numerical rows. It may be executed only after the frozen primary selection, immutable choice hash, and separate independent evaluation have completed successfully. It never changes a frozen action, the primary estimate, its verdict, source allocation, or model. No new simulator runs, fitting, recalibration, training, or reselection are authorized.

The input cohort is exactly sources 610084100–610084131, with at most two retained CARD_REWARD/BOSS_RELIC states per source and all eight sibling futures per retained action. Selection uses k=0–3 and evaluation uses k=4–7. Required custody is the reviewed collection freeze `1e8d1112a17c6126b3ccc446116b2fb74617fac35318acf1ca830bd392a177e1`, tooling bundle `2f56269cf2bb6f5cc001890499a460cba0dff3b5df601396b6f9fbd02a0c2857`, completed contract, frozen choices, completed primary report, and every underlying input hash. The eventual diagnostic invocation must record the then-known contract/choice/primary-report hashes before reading numerical rows. Invalid or missing siblings stop the diagnostic; no valid-only subset replaces the cohort.

## Units and fixed notation

For source s, selected state d, retained action a and future k, let Y(s,d,a,k) be finalWon. Let b(s,d) be the captured source action and g(r,s,d) the already frozen action for rule r (rollout, P0-s0, F2-s0). S={0,1,2,3}; E={4,5,6,7}. All differences compare sibling actions on the same k. The source run remains the independent resampling unit; states, actions and futures within it remain together.

Each summary reports its source, state, option and future counts. Overall effect summaries retain all 32 allocated sources and the primary zero-increment rule for valid sources without eligible states. Family-conditional summaries average states within each source that exposes that family, then average those sources, with the smaller denominator explicit. Also report each family's additive contribution to the original overall endpoint: sum its state gains within a source divided by that source's **total** selected-state count, then average all 32 sources. CARD and BOSS_RELIC contributions therefore sum to the primary overall gain. These two family summaries answer different questions and must not be interchanged.

For descriptive uncertainty, resample complete source clusters 10,000 times with RNG 20261008. No row-level or option-level bootstrap is allowed. Every exploratory interval is labelled pointwise and unadjusted for the several reported diagnostics; none constitutes a new success criterion. If an estimator is undefined in a bootstrap sample with no exposed sources, retain and report that count instead of silently assigning zero. Do not infer equivalence from a degenerate empirical interval.

## Fixed diagnostic tables

1. **Exposure and coverage (H10/H11).** Report allocated and valid sources, sources with zero/one/two selected states, CARD/BOSS sources and states by act, retained-option counts, and captured-baseline retention. For each frozen rule report changed actions, sources with any changed action, unchanged-baseline choices, and exact selection-score ties. A rule that does not change an action has zero intervention exposure at that state; this is different from an exposed action that produces no observed win difference. Report evaluation ceilings/floors: states where every retained option wins all four futures or loses all four. A ceiling in four draws does not establish true win probability one.

2. **Frozen-choice paired contrasts (H10/H11).** For each state and rule, report selection mean finalWon of the fixed choice and baseline, evaluation mean finalWon, paired selection gain ΔS, paired evaluation gain ΔE, and evaluation discordances. Include all fixed choices, including unchanged actions. Keep primary evaluation k separate from selection; do not pool them into an efficacy estimate. The case table includes exact source/state/type/act/floor/action keys and raw-file locators. Summarize by source and by family using the weights above.

3. **Selection optimism (H10).** For the already frozen rollout winner, report ΔS−ΔE. Among changed rollout actions, report counts with positive, zero and negative evaluation gain; retain all negative cases and sources. Separately report selection ties that retained the baseline. High positive selection advantages followed by zero/negative independent gains are compatible with noisy winner selection, but four evaluation draws do not prove that noise is the sole cause. Do not pick a new winner, report an evaluation-maximizing oracle as attainable gain, or silently extend K.

4. **Within-option and paired future dispersion (H13).** For every retained option, compute unbiased sample variance of binary finalWon separately on S, E, and the full eight draws. Full-eight variance is a descriptive variability estimate only, never a replacement effect estimate. For each non-baseline action also compute variance of the paired difference Y(a,k)−Y(b,k) on each block and all eight draws. This paired dispersion is more relevant to action comparison than separate Bernoulli variances because siblings share futures. Summarize per decision, then source and family, so options/states do not become independent replicates. Report the spread of option means alongside uncertainty, without labelling empirical spread as true signal or dividing by zero when the spread is absent.

5. **Model ranking versus calibration (H11).** Preserve the P0/F2 choices and their selection-side predictions. For every retained non-baseline action compare its fixed selection prediction gap with its independent evaluation gain, report positive/zero/negative sign tables, and keep zero/undefined cases visible. Absolute calibration is a separate diagnostic: for each model compute evaluation-branch predictions from that branch's post-action MAP using the same frozen 457-feature order, then report source/state/option-balanced signed bias mean(p−Y), Brier score mean((p−Y)^2), and fixed reliability bins [0,.2), [.2,.4), [.4,.6), [.6,.8), [.8,1]. Empty and sparse bins are explicit. These evaluation-MAP predictions are made only after primary completion and are never used for action choice. No fitted intercept, temperature, isotonic map, new model or threshold is produced. Global probability bias alone does not establish bad within-state ranking; ranking errors alone do not identify miscalibration as their cause.

6. **Post-MAP prediction and feature dispersion (H13).** On the complete sampled MAP rows, report per-option variance/range of P0/F2 probability predictions across futures. Report interpretable public feature dispersion for `curHp`, `maxHp`, `gold`, `deckSize`, `fmDElite`, `fmDRest`, `fmDShop`, `fmDBoss`, `fmCElite`, `fmCRest`, `fmCShop`, `fmCEvent`, `fmCMonster`, `fmCTreasure`, `curMapX`, and `curMapY`, only when those exact frozen columns exist; missing columns are reported rather than substituted. Compare CARD and BOSS_RELIC with source-weighted summaries. Do not combine heterogeneous feature units into one arbitrary variance score. Larger boss-relic MAP/prediction dispersion is compatible with next-act map uncertainty, but the data do not isolate a causal map effect from other action/future interactions.

## Interpretation and one prospective recommendation

The report gives one concise interpretation for H10, H11 and H13, with evidence for competing explanations. It does not rank the three rules by their best evaluation number or call any policy qualified. The intended distinctions are:

- **Little action exposure or an evaluation ceiling:** a near-zero gain is uninformative about a treatment rarely exercised. The best next experiment should improve prospective coverage of relevant public decision states, not train on flat labels.
- **Selection optimism plus large paired future dispersion:** noisy small-K ranking is plausible. The best next experiment is a separately preregistered, bounded larger-K test on fresh source decisions in the implicated family, with its own independent evaluation block and resource cap.
- **Independent action-value contrasts accompanied by model ranking errors:** feature/teacher mismatch is plausible. A future source-disjoint action-value or rank-learning experiment may be more informative than architectural expansion, but this diagnostic neither trains nor establishes that such learning will improve full-run wins.
- **Absolute bias with useful relative ranking:** recalibration and ranking are different problems. Bias alone does not justify changing action choice or deploying a calibrated leaf.
- **No supported separation of explanations:** recommend one fresh, more discriminating experiment with the strongest identified measurement gap; explicitly state that the present evidence is insufficient. Do not create a menu of automatic follow-up runs.

The eventual recommendation must name its primary hypothesis, the main competing explanation, one discriminating endpoint, fresh source allocation, smallest defensible resource budget, and independent evaluation boundary. It is a proposal for later authorization, not execution. If a population candidate succeeds elsewhere, this remains explanatory secondary evidence; if none succeeds, it supports choosing the single best next experiment.

The existing sampler preserves latent counters and eligible pool membership, so this is conditional action-value diagnosis under that sampler, not an exact player-information posterior. Historical P0/F2 teacher and feature limitations remain. All retained siblings are preserved; this is not evidence about unretained legal actions or a complete deployed policy. The four-source canary remains separate and is not pooled into tranche estimates. Protected TEST and final confirmation remain outside this analysis.
