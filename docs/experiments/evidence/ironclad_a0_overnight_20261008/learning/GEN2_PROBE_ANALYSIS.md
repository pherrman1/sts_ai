# Frozen small-canary comparison

This analysis uses the already authorized corrected GEN2 four-source canary and adds no game execution or training. The source freeze is `gen2_canary_3ed9/freeze.json` (SHA256 `8c7a1b9060159983b3a09e43e673e891c59be918e82c405784455143235d10bf`): source seeds 610084000–610084003, at most two retained CARD_REWARD/BOSS_RELIC states per source, four continuation futures per action. The coordinator supplies the completed contract receipt and its SHA256. A missing, invalid, changed, or incomplete input stops the lane and leaves a failure artifact.

The competing explanations are that the current source action ranking misses useful alternatives; historical P0/F2 value features identify better actions; or noisy two-draw selection and old teacher/feature distributions make such rankings unstable. This canary can reveal representation disagreement and validate the comparison machinery. It cannot identify a qualified stronger policy.

`analyze_gen2_probe.py select --contract PATH --contract-sha256 SHA` reads numerical selection labels and sampled post-action MAP features only for k=0,1. It freezes three rules for each captured source decision: highest mean finalWon on those two draws; highest mean P0-s0 prediction on those same two sampled MAP states; and highest mean F2-s0 prediction. Every exact tie favors the actual captured source action if tied, otherwise the lexicographically first semantic key. Mean model predictions use the 457 ordered feature names from the previously validated exports. No realized evaluation MAP contributes to any ranking. The resulting exclusive `gen2_probe_3ed9_choices.json` includes choices, selection scores, input hashes, script hash, and freeze timestamp. The command prints its SHA256.

Only after that artifact is saved and hashed does the distinct command `analyze_gen2_probe.py evaluate --choice-sha256 SHA` inspect k=2,3 numerical outcomes. It checks the frozen inputs and reports fixed chosen-action versus captured-baseline discordances for every state and each of the three rules. It averages paired gains within each source, then gives equal weight to each observed source; absent-state sources remain explicit nulls in the four-source allocation. It also reports the state-weighted descriptive mean and number of changed choices. There is no model reselection, highest-evaluation-rule selection, confidence-interval claim, continuation extension, or promotion rule.

The reviewed contract verifier previously reads all branches to check validity, completeness, coupling, and MAP joins without reporting evaluation outcomes. Hashing the files also covers all rows. During selection the analysis tokenizes CSV rows, checks k first, and never interprets, retains, ranks, or summarizes out-of-stage outcomes or features. The evaluation stage performs no new model predictions or action ranking.

Historical model custody and arithmetic parity are required. P0/F2 omit the four encounter-queue features but retain E1 potion/rarity counters and were trained on older privileged-teacher continuations. They remain unqualified for a fair deployed policy. The source sampler and retained action coverage are also narrow; different source decisions within a run are correlated, and two evaluation draws per state provide very coarse evidence. All numerical comparisons are diagnostic.

Focused synthetic checks: baseline-favored ties; lexicographic non-baseline ties; nonfinite score rejection; out-of-stage outcomes not interpreted; complete paired grid and future-hash coupling. No real numerical canary rows were inspected while writing these rules.
